# Seguimiento de Acervo Digital — 2026-10-13

## Estado del proyecto

- Proyecto en `master` y sincronizado con `origin/master` al preparar la release.
- Release `v0.1.0` publicada en GitHub.
- Stack: Java 17, Spring Boot 3.5.6, Maven, H2 y Flyway.
- Las pruebas se ejecutan desde Eclipse STS; las solicitudes HTTP manuales se validan con Bruno.

## Avances

- Tipos de elemento globales (`Libro`, `Pelicula`) y tipos personales.
- Definiciones configurables de atributos con tipos `TEXT`, `INTEGER`, `DECIMAL`, `DATE` y `BOOLEAN`.
- Plantillas globales consultables y protegidas frente a modificaciones normales.
- Fichas de catálogo con valores de atributos tipados y API paginada de consulta.
- Migraciones Flyway para tipos, definiciones y elementos; los datos de demostración se cargan solo con el perfil `dev`.
- Datos demo: 17 largometrajes dirigidos por Guy Ritchie, 10 de Quentin Tarantino y 10 clásicos de la literatura española.
- Hoja de ruta acordada hasta `1.0.0`.

## Validaciones y decisiones

- El usuario confirmó en STS/Bruno consultas de tipos y atributos, creación de un tipo personal, creación y actualización de un atributo, y que las pruebas del hito funcionaron.
- Maven y las pruebas se ejecutan desde STS, no desde la terminal del asistente.
- Los cambios Git se gestionan con SourceTree/STS; el asistente edita código y guía los commits, pushes, tags y releases.
- Las notas de trabajo se guardarán en un archivo nuevo por jornada: `docs/YYYY-MM-DD.md`.
